# Online Book Store

## Project Description

An online bookstore application developed collaboratively
using Git and GitHub.

## Modules

1. Book Display
2. Book Search
3. Shopping Cart
4. Customer Management

## Technologies

* HTML
* CSS
* JavaScript
* Git
* GitHub

## Git Branching Strategy

The main branch contains the integrated application.
Each developer works on a separate feature branch.

## Collaboration Workflow

* Create feature branches
* Make incremental commits
* Push changes to GitHub
* Create pull requests
* Resolve merge conflicts
* Test the integrated application

Bookstore theme: Classic Blue with Modern Green accents
